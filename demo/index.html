dsh-view-switcher

Plugin DeepSeek Harness (DSH) dua-half (Host + Client) untuk mengatur lebar tampilan web dan menginspeksi elemen.

Fitur

  1. Sakelar Tampilan: mode AUTO, MOBILE, TABLET, DESKTOP, dan FULLHD.
  2. Inspektur Elemen: tekan F1, arahkan kursor, lalu klik untuk menyalin CSS selector ke clipboard.
  3. Arsitektur dua-half: host Node.js inert, semua UI di client lewat dsh.client.

Build & Test

pnpm install
pnpm build      # tsc → dist/
pnpm test       # node:test + jsdom
